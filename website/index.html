WHY NOT DOCKER

Native services, not containers

01

Real Windows services

Every app runs under the Service Control Manager via NSSM — starts at boot, survives logoff, restarts itself if a process dies. No always-on desktop session required.

02

Wired together on install

Root folders, SABnzbd/qBittorrent hookups, Prowlarr → *arr sync, and Seerr's connections to Jellyfin, Sonarr and Radarr are all set through each app's own API the moment it comes online.

03

TRaSH-Guides baked in

Quality definitions sync through Recyclarr on install, the same tool the TRaSH-Guides project itself now points people to for staying current.

WHAT THE INSTALLER DOES

One script, in order

01

Resolve current releases

Queries each project's GitHub releases at run time and downloads the matching Windows build — never a version pinned to go stale.

02

Install as a service, not a login shortcut

Each app's own installer just adds a run-at-login entry. NSSM wraps the binary as a proper auto-starting, self-healing Windows service instead.

FIX: apps now survive logoff and reboot
03

Capture API keys, configure root folders

Reads each app's generated API key straight from its config, then sets its media root folder and naming through the REST API — no clicking through setup wizards.

04

Wire SABnzbd, qBittorrent and Prowlarr to everything

Both download clients are registered in every *arr app with the right category; every *arr app is registered inside Prowlarr for indexer sync.

05

Sync TRaSH-Guides quality definitions

Recyclarr runs against Sonarr and Radarr to pull current quality definitions, the piece of TRaSH-Guides config that changes too often to hardcode safely.

06

Build and wire Seerr

Seerr ships no Windows installer, so it's built from source with Node.js and pnpm, then signed in to Jellyfin, connected to Sonarr and Radarr, and its libraries enabled — entirely through its own API.

07

Stand up the dashboard

A status page goes live as its own service — host CPU/RAM, every app's real numbers, storage, and recent activity, refreshing on its own. Not a script window you have to leave open.

GET IT

Run it on a fresh Windows 11 box

# double-click and go
> start.bat

# or, from an elevated PowerShell window
PS> .\Install-REGTechesMediaStack.ps1

# prefer a setup window with app checkboxes?
PS> .\REGTechesMediaStack-Setup.ps1

What you'll need

A clean Windows 11 install and about ten minutes (a bit longer the first time, since Seerr builds from source). The script re-runs safely — it only does work that isn't already done.

  • Add your own indexers in Prowlarr once it's up; they sync everywhere else automatically.
  • Everything installs under one folder, so moving or removing the stack later stays contained.
  • Don't need every app? -SkipApps and -SkipSeerr flags let you leave pieces out.
